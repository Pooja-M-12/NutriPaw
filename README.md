# NutriPaw

NutriPaw is a multi-page website focused on pet care, services, and nutrition awareness.

## Features
- Multi-page navigation (Home, Services, Products, Cart, etc.)
- Pet care and nutrition information
- Clean and user-friendly interface
- Basic user interaction (login, booking, etc.)

## Tech Stack
- HTML
- CSS
- JavaScript

## About
This is my first web development project where I designed and developed a complete website layout and structure. It helped me understand UI design, navigation, and real-world application flow.
